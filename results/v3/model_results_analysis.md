## 결과표 지표 설명

| 지표 | 계산 방법 |
| --- | --- |
| Nested OOF F1 | 11~40번 폴더를 5개 묶음으로 나누고 한 묶음씩 평가용으로 남겨 뒀다. 나머지 폴더에서 내부 교차검증으로 설정을 고르고 학습한 뒤, 평가용 폴더에서 얻은 예측을 모두 모아 F1을 계산했다. |
| OOF 정밀도 | 위 교차검증에서 불량으로 판정한 CSV 중 실제 불량인 비율이다. |
| OOF 재현율 | 위 교차검증에서 실제 불량 CSV 중 불량으로 찾아낸 비율이다. |
| 탐색 시험 F1 | 모델 설정을 고정하고 11~40번 전체로 다시 학습한 뒤, 1~10번 폴더의 예측으로 계산한 F1이다. 1~10번은 이전 실험에서도 확인했으므로 탐색 시험으로 기록했다. |
| 시험 정밀도 | 1~10번에서 불량으로 판정한 CSV 중 실제 불량인 비율이다. |
| 시험 재현율 | 1~10번에서 실제 불량 CSV 중 불량으로 찾아낸 비율이다. |

Nested는 평가용 폴더를 나누는 바깥 교차검증과 설정을 고르는 안쪽 교차검증을 함께 썼다는 뜻이다. OOF(Out-of-Fold)는 해당 폴더를 학습에서 뺀 모델로 얻은 예측을 뜻한다. F1은 정밀도와 재현율의 조화평균이다.

세부 검증 결과는 [교차검증 모델 비교표](model_comparison.csv)와 [폴더별 교차검증 지표](motor_group_metrics.csv)에 있다.

## 로지스틱 회귀

- 특징 `v3_amplitude_invariant_16`, 설정 `{"C":0.01}`, 판정 기준 0.5
- 시험에서 정상 정분류 1039개, 정상 오탐 2개, 불량 누락 492개, 불량 탐지 559개

시험에서 정상 1,041개 중 2개만 불량으로 오판했지만, 실제 불량 1,051개 중 492개를 놓쳤다. 특히 9번은 불량 102개를 모두 놓쳤고, 2번에서도 102개 중 100개를 놓쳤다. 높은 시험 정밀도와 낮은 재현율을 함께 봐야 한다.

## 랜덤포레스트

- 특징 `v3_amplitude_invariant_16`, 설정 `{"max_depth":null,"min_samples_leaf":2,"n_estimators":200}`, 판정 기준 0.5
- 시험에서 정상 정분류 1041개, 정상 오탐 0개, 불량 누락 146개, 불량 탐지 905개

교차검증 F1이 가장 높아 최종 후보로 선정됐다. 시험에서 정상 1,041개를 모두 맞췄지만, 놓친 불량 146개 중 94개가 10번 폴더에 집중됐다. 1~9번의 폴더별 F1은 0.9319~1.0000이고, 10번은 0.2540이다.

## RBF SVM

- 특징 `v3_amplitude_invariant_16`, 설정 `{"C":10,"gamma":"scale"}`, 판정 기준 0
- 시험에서 정상 정분류 1037개, 정상 오탐 4개, 불량 누락 82개, 불량 탐지 969개

탐색 시험에서는 F1과 재현율이 가장 높았다. 불량 82개를 놓쳤고 그중 51개가 10번 폴더에 집중됐다. 정상 오탐 4개는 모두 4번 폴더에서 나왔다. 최종 후보는 기존 교차검증 기준을 유지한다.

## v1~v3 결과 비교

| 버전 | 모델 | 검증 F1 | 1~10번 시험 F1 |
| --- | --- | ---: | ---: |
| v1 | 로지스틱 회귀 | 0.6562 | 0.9222 |
| v1 | 랜덤포레스트 | 0.5553 | 0.9262 |
| v2 | 로지스틱 회귀 | 0.7742 | 0.8699 |
| v2 | 랜덤포레스트 | 0.7747 | 0.9368 |
| v3 | 로지스틱 회귀 | 0.8683 | 0.6935 |
| v3 | 랜덤포레스트 | 0.9172 | 0.9254 |
| v3 | RBF SVM | 0.9067 | 0.9575 |

v1·v2는 35~40번 폴더에서 검증했고, v3는 11~40번에서 모터 폴더 단위 중첩 교차검증을 했다. 검증 점수는 평가 방식이 다르므로 버전 간 성능 향상을 판단하는 데 직접 비교하기 어렵다. v3의 시험 F1은 기존에 확인한 1~10번을 재사용한 탐색 결과다.

같은 1~10번 시험에서 로지스틱 회귀가 찾아낸 불량은 v2의 809개에서 v3의 559개로 줄었다. 불량 누락은 242개에서 492개로 늘었고, 재현율은 77.0%에서 53.2%로 떨어졌다. v3에서 RMS·표준편차 등 진동 크기 특징을 파형 모양 특징으로 교체한 것이 영향을 줬을 가능성이 있다. 개별 특징의 영향은 특징만 바꾼 비교 실험으로 확인해야 한다.

교차검증 F1을 기준으로 랜덤포레스트를 최종 후보로 선정했다. 1~10번 탐색 시험에서는 RBF SVM의 F1이 가장 높았다.
