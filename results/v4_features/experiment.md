# v4 (3주차) — 특징 추출 방법 비교 (랜덤포레스트 설정 고정)

## 목적

2주차 v3 최종 랜덤포레스트를 기준으로, 특징 추출 방법만 바꿨을 때 처음 보는 모터 번호에 대한 불량 탐지 F1이 개선되는지 확인한다. Welch와 웨이블릿 패킷(WPT)을 각각 16대역·32대역으로 실행해, **같은 대역 수에서 방식이 달라진 효과**와 **같은 방식에서 대역 수를 늘린 효과**를 분리한다. 설정을 고정한 특징 비교이므로, v3 보고서의 중첩 교차검증 F1(0.9172)과 직접 비교하지 않고 같은 조건에서 다시 실행한 A를 기준으로 개선 폭을 계산한다.

## 데이터와 평가 조건

- 개발 데이터: 정상·불량 11~40번 폴더만 사용한다(정상 3,172 + 불량 3,136 = 6,308 CSV, 모두 1,024 샘플). **1~10번은 읽지 않았다.**
- CSV 한 개 = 예측 한 건이고, 불량(abnormal)이 양성 클래스이다.
- 그룹은 모터 번호이다. 정상·불량 폴더에서 같은 번호는 같은 그룹으로 묶었다.
- 분할 세트는 3개이고, 모두 모터 번호 단위 5-fold(각 fold 6개 번호)이다. 각 세트 안에서 다섯 방법은 똑같은 학습·검증 번호를 쓴다.
  - `v3_outer_folds`: `results/v3/nested_cv_folds.csv`의 v3 바깥 5-fold를 복원했다. 세 모델의 기록이 같음을 확인했다. **A의 설정을 고른 분할이라 A에 유리하므로 참고용으로만 본다.**
  - `motor_shuffle_seed42`, `motor_shuffle_seed73`: `numpy.random.default_rng(seed).permutation(11..40)`을 5등분했다.
  - 전체 목록은 `split_definitions.csv`에 있다.
- 주 지표는 각 분할 세트에서 검증 예측을 모두 합친 OOF F1이다. Precision, Recall, FP, FN도 함께 기록한다.

## 특징

| 키 | 방법 | 개수 | 정의 |
| --- | --- | ---: | --- |
| A | v3 기준선 | 16 | `preprocess_v3.AMPLITUDE_INVARIANT_FEATURES_V3`. 기존 `extract_features_v2` + `extract_shape_features_v3` 사용 |
| W16 / W32 | Welch | 16 / 32 | 평균 제거 → `scipy.signal.welch`(Hann, nperseg 512, noverlap 256, detrend 없음, density) → DC 제외 양의 주파수를 동일 폭 n대역으로 나눔 → 대역 전력 / 전체 전력 → log10 |
| P16 / P32 | sym8 웨이블릿 패킷 | 16 / 32 | 평균 제거 → RMS 정규화 → `pywt.WaveletPacket(sym8, periodization)`을 4단계(16노드) / 5단계(32노드)까지 분해 → `order="freq"`로 정렬 → 노드 계수 제곱합 / 전체 노드 합 |

**샘플링 주파수**
- v2와 같이 각 CSV의 시간 열 간격 중앙값으로 계산했다(`preprocess_v2.extract_features_v2`).
- 6,297개 파일이 401.6 Hz, 11개 파일이 400.0 Hz였다.
- 대역을 Nyquist 비율로 정의했으므로, 파일마다 fs가 조금 달라도 같은 PSD 빈 범위를 쓴다.

**Welch 대역 경계**
- j번째 대역은 ((j−1)/n·Nyquist, j/n·Nyquist]이다. DC는 제외했고 Nyquist 빈은 마지막 대역에 넣었다.
- 대역마다 PSD 빈이 16대역이면 16개씩, 32대역이면 8개씩이다.
- fs 401.6 Hz 기준 대역 폭은 16대역에서 약 12.55 Hz, 32대역에서 약 6.27 Hz이다.

**0 처리**
- Welch: 전체 전력이 0이면 모든 대역을 1/n으로 둔다. 상대 전력이 1e−12 미만이면 1e−12로 잘라 log10을 적용한다.
- WPT: RMS가 0이면 모든 노드를 1/n으로 둔다.
- 이번 데이터에서는 해당하는 경우가 모두 0건이었다.

**순서 확인**
- 47·110·160 Hz 사인파를 넣어 보니, 네 방법 모두 기대한 대역(16대역 기준 4·9·13번, 32대역 기준 8·18·26번)에서 최대값이 나왔다.
- WPT 노드는 근사적인 주파수 대역이다(필터가 겹쳐서 경계가 정확하지 않음).

## 모델 (다섯 방법 공통, 고정)

- 모델: `RandomForestClassifier(n_estimators=200, max_depth=None, min_samples_leaf=2, random_state=42, n_jobs=-1)`
- 나머지 옵션은 v3 `_make_model`과 같이 scikit-learn 기본값이다.
- 불량 판정은 `predict_proba ≥ 0.5`이다(v3 `_predict`와 같은 규칙).

## 해석과 한계

- 평균 F1이 가장 높은 W32(Welch 32대역)를 다음 단계의 1순위 후보로 둔다.
- 대역 수 효과는 두 방식 모두, 방식 효과는 두 대역 수 모두에서 세 분할 내내 같은 방향이었다. 다만 크기가 0.001~0.012로 작다. 모터 하나의 판정이 뒤집힐 때 F1이 약 0.016~0.018 움직이므로, 모터 1개 수준보다 작은 차이이다.
- 모터가 30개뿐이다. 같은 30개를 다시 나눈 3개 분할로는 모터 표본에서 오는 변동이 줄지 않는다.
- 랜덤포레스트 설정과 임계값 0.5는 v3가 A에 맞춰 고른 값이다. W/P에 맞춘 설정이 아니다.
- 점수가 0.99 수준이다. 이것이 모터 상태 차이를 반영하는지, 측정 조건 차이를 학습한 것인지는 아직 확인하지 않았다.

## 후속 실험 (이번에 실행하지 않음)

- A + 주파수 특징 결합 비교
- 임계값·하이퍼파라미터를 안쪽 교차검증으로 고르는 중첩 교차검증으로 W32 재평가
- 반복 분할 확대(10회 이상)와 모터 단위 부트스트랩으로 ΔF1의 신뢰구간 계산
- 모터 24의 누락 원인 분석
- 최종 설정 확정 후 11~40번 전체 학습 → 1~10번 1회 평가 코드 작성
