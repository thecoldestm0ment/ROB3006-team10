# 기계학습론 IC-PBL 최종보고서 · 10조

작성 양식입니다. 2주차에 전체 초안을 완성하고, 3주차 피드백과 최종 평가 결과를 반영합니다.

## 1. 서론

- 모터 불량 판별의 필요성
- 해결할 문제와 프로젝트 목표

## 2. 제안하는 방법

### 2.1 데이터와 전처리

- 데이터 구성과 샘플 단위
- 특징 정의와 선택 이유
- 학습·검증·시험 분리 방법

### 2.2 로지스틱 회귀

- 모델 원리와 선택 이유
- 표준화와 모델 설정

### 2.3 랜덤 포레스트

- 모델 원리와 선택 이유
- 모델 설정

## 3. 성능 평가

### 3.1 실험 조건과 평가 지표

실제 사용한 데이터 분할·환경·지표 정의를 적습니다.

### 3.2 내부 검증 결과와 개선 과정

두 모델의 비교와 개선 실험을 실험 ID에 연결해 정리합니다.

### 3.3 최종 시험 결과와 재현 확인

방법과 설정을 확정한 뒤 수행한 최종 시험 결과를 적습니다. 실행 전에는 결과 수치를 채우지 않습니다.

## 4. 결론

- 확인한 결과와 의미
- 한계와 향후 개선 방향

## 5. 참고한 자료와 문헌

실제로 참고한 자료만 기록합니다.

## 6. 소감

각 팀원이 실제 수행한 역할과 배운 점을 작성합니다.
