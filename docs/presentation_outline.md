# 발표자료 구성안

PPT 파일은 `docs/`에 직접 저장합니다. 예: `presentation_draft.pptx`, `presentation_final.pptx`.

| 순서 | 내용 | 준비할 자료 |
| --- | --- | --- |
| 1 | 과제 목표와 해결할 문제 | 모터 정상·불량 판별 배경 |
| 2 | 데이터와 실험 조건 | 정상·불량 파형, 분할 기준 |
| 3 | 공통 전처리와 두 모델 | 특징 설명, 모델별 핵심 원리 |
| 4 | 모델 비교와 개선 과정 | 동일 검증 조건의 성능표, 개선 전후 결과 |
| 5 | 최종 시험 결과 | 확정 후 평가한 수치와 혼동행렬 |
| 6 | 결론 | 결과 해석, 한계, 배운 점 |

발표 시간·제출 형식은 수업 공지에 맞춥니다. 보고서와 PPT의 실험 ID·수치를 맞춥니다.
