# 최종 시험 점수 실행 코드

이 폴더는 CSV 단위 최종 시험 점수를 출력하는 데 필요한 최소 코드입니다. Welch 32대역 특징과 랜덤포레스트 설정을 사용합니다.

## 데이터 폴더

원본 데이터는 이 폴더에 넣지 않습니다. 원본 데이터 폴더의 경로를 실행할 때 지정하세요. 폴더 구조는 다음과 같아야 합니다.

```text
데이터 폴더/
├── normal/
│   ├── 1/time_vib/*.csv
│   └── ...
└── abnormal/
    ├── 1/time_vib/*.csv
    └── ...
```

각 CSV는 헤더 없는 시간·진동 측정값 2열이어야 합니다.

## 설치 및 실행

Python 환경에서 이 폴더로 이동한 뒤 필요한 라이브러리를 설치합니다.

```bash
python -m pip install -r requirements.txt
python -m src.run_final_test --data-root "데이터 폴더 경로"
```

예를 들어 Windows에서는 다음처럼 실행할 수 있습니다.

```powershell
python -m src.run_final_test --data-root "C:\데이터\IC-PBL 기계학습론"
```

코드는 11~40번 폴더로 학습한 뒤 1~10번 폴더를 평가해 CSV 단위 F1, 정밀도, 재현율, 혼동행렬을 화면에 출력합니다. 결과 파일은 만들지 않습니다. 1~10번은 프로젝트 이전 실험에서도 평가한 기존 시험 세트이므로, 점수를 확인한 뒤 모델 설정을 조정하는 데 사용하지 마세요.
